# 💎 𝐃𝐢𝐚𝐦𝐨𝐧𝐝 𝐏𝐫𝐢𝐜𝐞 𝐏𝐫𝐞𝐝𝐢𝐜𝐭𝐢𝐨𝐧

A machine learning project built with Python to predict diamond prices, with a simple interactive web app made using Streamlit.

### ✨ 𝐀𝐛𝐨𝐮𝐭 𝐭𝐡𝐞 𝐏𝐫𝐨𝐣𝐞𝐜𝐭

I built this project to practice machine learning and understand how a trained model can be used in a real application.

The project includes data analysis in a Jupyter Notebook, saved model files, and a Streamlit app where users can enter diamond details and get a price prediction.

### 🛠️ 𝐓𝐞𝐜𝐡 𝐒𝐭𝐚𝐜𝐤

* Python
* Pandas & NumPy
* Seaborn
* Scikit-learn
* Streamlit
* Jupyter Notebook

### 📂 𝐏𝐫𝐨𝐣𝐞𝐜𝐭 𝐅𝐢𝐥𝐞𝐬

* `app.py` — Streamlit application
* `diamonds prediction.ipynb` — notebook for analysis and experimentation
* `diamond_knn.pkl` — saved KNN model
* `diamond_scaling.pkl` — saved feature scaler
* `cut_le.pkl`, `color_le.pkl`, `clarity_le.pkl` — saved encoders
* `requirements.txt` — Python dependencies

### 🚀 𝐇𝐨𝐰 𝐭𝐨 𝐑𝐮𝐧

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
cd Diamond-Price-Prediction-ML
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

**2. Create and activate a virtual environment**

```bash
python -m venv .venv
```

On Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

**3. Install the dependencies**

```bash
pip install -r requirements.txt
```

**4. Start the app**

```bash
streamlit run app.py
```
